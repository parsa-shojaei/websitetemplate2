## ✨ Overview

**دفترِ شب (DAFTAR-E SHAB)** — meaning *"The Night Notebook"* — is a meticulously designed Persian blog template that treats content as the star. Unlike generic blog themes that treat articles as filler, this template ships with **12 fully-written, editorial-grade articles** in Persian, covering topics from artificial intelligence and UX design to philosophy, psychology, technology, and travel.

The visual identity blends a **midnight indigo** background with **electric violet** and **cyan** accents — a modern, intellectual aesthetic that respects both the text and the reader.

> **Design Philosophy:** *Content is king — but a king deserves a palace.*

## 🟦 WordPress Ready

While this template is delivered as **pure HTML/CSS/JS** for maximum portability and performance, **the same design can be fully reproduced on WordPress** with any of the following approaches:

### Option 1 — Elementor + Astra (Fastest)
Rebuild each section visually using Elementor's free/pro widgets. The hero orbital can be recreated with an HTML widget or Lottie. Article grid → **Posts Grid** widget. Modal reader → **Popup** template.

### Option 2 — Custom Child Theme (Most Faithful)
1. Create a child theme of a lightweight base (e.g., **Twenty Twenty-Four** or **GeneratePress**).
2. Copy all CSS from `index.html` into `style.css`.
3. Map sections:
   - Hero → `front-page.php`
   - Featured article → `single.php` template
   - Article grid → `archive.php` with custom WP_Query
   - Modal reader → JavaScript that fetches post content via REST API
4. Register custom post types if needed.

### Option 3 — Block Theme (FSE) — Recommended for 2024+
Convert each section into reusable **Block Patterns** using `theme.json` for the color palette and typography scale. This gives editors a native WordPress experience with the same visual result.

### Option 4 — Headless WordPress
Keep this exact HTML as the frontend, connect to WordPress REST API for posts. Best of both worlds: same design + full CMS. Use Next.js, Nuxt, or plain JS fetch.

### 🧩 Suggested WordPress Plugins
| Purpose | Plugin |
|---------|--------|
| SEO | **Rank Math** or Yoast SEO |
| Cache | **LiteSpeed Cache** or WP Super Cache |
| Forms | **WPForms** or Contact Form 7 |
| RTL support | **Astra** or **Twenty Twenty-Four** (native RTL) |
| Persian fonts | **WP-Parsidate** or local font upload |
| Popup/Modal | **Popup Maker** |
| Article view count | **WP-PostViews** |

> **Bottom line:** WordPress can deliver this exact experience — either through a page builder in a day, or as a custom theme in a week. This HTML template doubles as a **design reference** for that conversion.

## 🎨 Customization

### Colors (CSS Variables)
```css
:root {
  --bg: #070a14;          /* Midnight indigo base */
  --violet: #8b5cf6;      /* Primary accent */
  --cyan: #22d3ee;        /* Secondary accent */
  --pink: #f472b6;        /* Tertiary accent */
  --grad: linear-gradient(135deg,#8b5cf6,#22d3ee);
}
```

### Adding a New Article
Open `index.html`, find the `articles` array in the `<script>` block, and append:

```js
{
  cat:'دسته‌بندی',
  emoji:'📝',
  title:'عنوان مقاله',
  excerpt:'خلاصه‌ی ۲-۳ خطی برای کارت مقاله',
  date:'۱۴۰۳/۰۱/۰۱',
  readTime:'۵ دقیقه',
  views:'۰',
  content:`<h1>عنوان</h1><p class="lead">مقدمه...</p>...`
}
```

The grid, modal reader, and count update automatically.
